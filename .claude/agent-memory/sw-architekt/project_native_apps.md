Fakturus Track entwickelt native iOS- und Android-Apps als Ersatz fuer die bestehende MAUI/Blazor-Hybrid App.

**Why:** Die MAUI-App (WebView-basiert) wirkt nicht professionell genug. Native Apps bieten bessere UX, Performance und App-Store-Akzeptanz. fakturus.poi beweist dass natives Development funktioniert.

**How to apply:** Alle Architektur-Entscheidungen muessen die Migration beruecksichtigen. Backend bleibt unveraendert (gleiche API). Gleicher B2C-Tenant. Sync-Logik aus MAUI-App als bewaehrte Referenz nutzen. Zeitplan: Phase 1 ab April 2026 (8 Wochen Kern-Zeiterfassung).
